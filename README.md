# CTF Writeups

Notes and solutions from CTFs, boxes, and wargames as I work through them. Written for future-me as much as anyone else — dead ends included, not just the clean solve path.

---

### Structure

- **THM/**, **HTB/**, **CyLab/** — platform-based challenges, split by difficulty (Easy / Medium / Hard)
- **OverTheWire/** — wargames, split by challenge set (Bandit, etc.), then by level as I go
- **Competitions/** — one folder per event (BSides Canberra, CTFtime entries, etc.)

Each individual challenge gets its own folder with a `README.md` writeup, plus any scripts or files used to solve it.

---

### Writeup format

Every writeup roughly follows:

- **Summary** — what the challenge was
- **Approach** — what I tried, in order, dead ends included
- **Solution** — the path that actually worked
- **What I learned** — new tool or concept
